## Состояние гидравлики (конспект, проверено 2026-08-08)

### Где живёт код
- `elou_avt_twin/calculation_core/hydraulics/line_hydraulics.py` — стационарный решатель разветвлённой гидравлической сети.
- `elou_avt_twin/simulation_core/engine.py` — построение сети (`_build_line_trees`, `_hx_channel_info`, `_vessel_boundary`, `_pipe_resistance`, `_static_head`, `_make_pump_head`, `_solve_line_hydraulics`).

### Единицы
- Давление в Па (абсолютное), расход кг/с, плотность 850 кг/м³.
- Поток-порог `ZERO_FLOW = 1e-6` (ниже — «заперто»), абсолютный потолок `P_FLOOR = 1000.0` (ниже вакуума).

### Модель элементов (словарь `nodes`/`children`)
- `source` — жёсткая граница давления `p_src`; тянет сколько позволяет сеть. `q_src_limit` (параметр `flow_kg_s`): выше лимита давление проседает, пока сеть не начнёт брать ровно лимит.
- `sink` — жёсткое давление `sink_p` (граница, от которой якорятся).
- `valve` — квадратичное сопротивление `k`, `k = (1/(ρ·Cv²))·((1-x)/x)²` (`valve_resistance`). Полностью открытый (`position>=1.0`) становится `passthrough` с `k=_K_EPS`. Закрытый (`<=1e-6`) — `closed`, изолирует всё ниже по дереву.
- `res` — сопротивление с квадратичным падением `k·q²` + статический член `head` (Па, `_static_head`: ρ·g·Δz). Используется для труб и каналов ТО.
- `res` + `max_dp` — жёсткий потолок перепада: `dp = min(k·q², max_dp)`.
- `pump` — `head` = callable H(Q) из реальной кривой насоса (в Pa); если насос выключен/сломан → 0.
- `pass` — транзитный узел, нулевой перепад (ёмкости, колонна с одним входом).

### Решатель `solve_branched_network(p_src, q_src_limit, nodes, children, root)`
1. **subtree_flow(nid, p)** — «спрос» ветви при давлении на входе (рекурсия, бисекция монотонных остатков). Если за элементом один достижимый sink — явная формула `sqrt((p+sink_p...)/k)` через `_reachable_sink_p`/`_sink_behind_pass`.
2. **root_flow(p_src)** — общий расход источника. При `q_src_limit` проседание давления (бисекция до P_FLOOR).
3. **distribute(nid, p_in, q)** — прямой проход сверху вниз: один расход через серию, разветвление пропорционально спросам ветвей на общем давлении вилки (`p_fork` ищется бисекцией). Узел с `q<=ZERO_FLOW` — изолируется на своём давлении sink (или `max_sink_p`).
4. **`_anchor_from_sinks(cur)`** — обратный проход снизу вверх: sink — жёсткая граница, насос даёт ровно столько напора, сколько нужно каскаду (ограничено максимумом кривой), полностью открытый клапан не роняет давление. `result[nid] = {flow, p_in, p_out}`.

### Теплообменник
- Два независимых гидравлических контура (hot/cold), ключ узла `f"{nid}:{port}"` (`_HX_PORT_PAIRS`), потоки не смешиваются.
- Канал = `res` с `k = delta_p / q_ref²`; по умолчанию `delta_p` = `_HX_DEFAULT_DP = 10132.5 Па (0.1 атм)`, `q_ref` = `nominal_flow`/`flow_kg_s` (по умолчанию 100).
- **Жёсткий максимум перепада канала: `max_dp = _HX_MAX_DP = 50662.5 Па (0.5 атм)`** (ТЗ), переопределяется параметром `max_delta_p`. `delta_p <= 0` → `pass`.
- Следствие: при большом расходе канал насыщается 0.5 атм, давление на входе канала = p_sink + 0.5 атм; при малом расходе перепад квадратичный `k·q² < 0.5 атм`.

### Ёмкости (elou/separator/tank) — инвентарные границы
- `_vessel_boundary`: `p_out = p_base + ρ·g·level`, `k_drain` для дренажа из уровня.
- В дереве: завершают верхний контур как `sink` (vessel), дальше строят НОВОЕ дерево с корнем-ёмкостью (`is_vessel=True`, перед выходом стоит `res` `{root}__drain`). Уровень интегрируется: `dL/dt = (Qin−Qout)/(ρ·A)` (`_integrate_levels`).
- Сливной `res` (`k_drain`) понижает давление: при больших расходах насос на всасе может получить низкое (0.35 бар) давление — допустимо.

### Разрывы дерева
- Точки слияния (`indeg > 1`), многоходовые устройства без парных портов, колонна с несколькими входами, ТО без достижимого sink через парный порт — дерево не строится, узел остаётся legacy-потоку.

### Схема по умолчанию (default.json)
- source → val_1 → elo_1(ёмкость) → pump(→ val_7) → hot-канал ТО → sink. Проверено: при полном открытии расход ~223 кг/с, насос поднимает ровно до p_sink + 0.5 атм (1.52 бар), dp_hot = 0.5 атм (насыщение); при 215 кг/с dp_hot = 0.46 атм (квадратично).
